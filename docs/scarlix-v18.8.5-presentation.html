Aktuálny systém v18.8.5
SCARLIX OS je bootstrap installer — žiadne ISO. Spustí sa bash install.sh na čistej EndeavourOS inštalácii a za 5 fáz postaví kompletný AI stack s GPU podporou, Dockerom, a ScarliHQ dashboardom. Všetko je fail-closed — ak niečo zlyhá, systém to povie, nie ticho pokračuje.

TIER 2
vLLM v0.8.0 — GPU 1, TP=1 (experimental, .experimental gate)
TIER 4
BeeLlama / llama.cpp — CPU offline fallback, Q4_K_M GGUF
FALLBACK
Ollama 0.5.4 — CPU tertiary, qwen2.5:3b starter model
GATEWAY

DASH
ScarliHQ — Go binary, Alpine, token auth, WS ticket system, host-bridge architecture
Bezpečnostná architektúra: ScarliHQ kontajner NEMÁ docker.sock, NEMÁ nvidia runtime. Komunikuje len cez súborový bridge — zapisuje desired-mode do bridge-input/ (UID 65532), root host-bridge timer (5s) číta cez Go O_NOFOLLOW atomic reader a vykonáva privileged operácie. Žiadny TOCTOU, žiadny symlink attack.
Mode lifecycle: scarlix-mode ai spustí SGLang → vLLM → BeeLlama → Ollama fallback chain + LiteLLM gateway. scarlix-mode stop zastaví všetko vrátane LiteLLM. Game/Creative/TV módy zastavia AI + uvoľnia VRAM. Healthcheck kontroluje všetky kontajnery + API endpoints.

Chapter 03
ScaRgeN Visions 1-10
Pôvodných 10 vízií pre SCARLIX OS v20+ — AI-native operacný systém, kde AI nie je aplikácia ale vrstva ako networking alebo filesystem.
VISION 01
AI-Native Kernel Scheduler

Nahradí systemd timer pre AI workload. eBPF programy sledujú nvidia-smi + /proc/meminfo + AI API latency. Keď GPU memory pressure stúpne, scheduler automaticky zníži --max-running-requests bez reštartu. Žiadny AI request nezaseknutý kvôli pacman -Syu.

Pre nás: zero-latency AI scheduling. Pre iných: AI workload nikdy nezaseknutý OS update.
VISION 02
Neural Model Router (NMR)

Trénujúci router ktorý sa učí latency/cost/quality tradeoff per-user. Malý ML model (LogisticRegression) beží na CPU. Analyzuje TTFT + tok/s + context usage a dynamicky routuje. Krátke chaty → Ollama (rýchlejšie), dlhé kontexty → SGLang (lepšie KV cache).

Pre nás: automaticky najrýchlejší backend. Pre iných: žiadne manuálne prepínanie modelov.
VISION 03
Homomorphic Encryption Layer

FHE (fully homomorphic encryption) vrstva medzi klient a AI inference. Requesty sú encrypted end-to-end — ani host nemôže čítať prompt obsah. Pre zdravotné otázky, finančné poradenstvo. OpenFHE alebo Concrete-ML. Optional: scarlix-mode ai --private.

Pre nás: 100% private AI pre rodinu. Pre iných: first OS s encrypted inference — GDPR-ready.
VISION 04
Federated Learning Mesh

Viacero SCARLIX inštalácií (doma, v chate, u kamaráta) zdieľajú KV cache fragmenty cez Tailscale mesh bez zdieľania modelov. Latencia klesá, privacy zostáva. 3 nodes = 3x viac KV cache kapacity bez ďalšej VRAM.

Pre nás: AI na chate rovnako rýchla ako doma. Pre iných: komunita bez cloud dependency.
VISION 05
Voice-First OS Shell

Whisper STT + Piper TTS integrované do shell úrovne. "Scarlix, spusti AI" nahlas. Chybové hlášky sa čítajú nahlas. Dashboard ovládaný hlasom — žiadny monitor nepotrebný pre základné operácie. Wake word: "Scarlix".

Pre nás: deti a starí rodičia môžu používať AI bez klávesnice. Pre iných: first voice-native Linux OS.
VISION 06
Self-Healing BTRFS Snapshots

BTRFS send/receive pre incremental AI model snapshots. Keď healthcheck zlyhá 3x po sebe, ScaRgeN automaticky rollbackne /models na funkčný snapshot + reštartuje engine. Zero-downtime recovery. Snapper pre /models subvolume.

Pre nás: žiadne manuálne opravy po update. Pre iných: self-healing OS ako Kubernetes pre kontajnery.
VISION 07
Quantum-Safe Authentication

Kyber/Dilithium post-quantum kryptografia. Bearer token auth nahradený PQ signatures + WebAuthn (fingerprint/FaceID). Future-proof proti quantum hrozbám. Každý rodinný člen má vlastný PQ keypair. liboqs (Open Quantum Safe).

Pre nás: 10+ rokov lifetime zabezpečené. Pre iných: first quantum-safe home OS.
VISION 08
Edge AI Cache (EAC)

Semantic deduplication cache — embedding similarity > 0.95 = cache hit. Rodinné otázky sa opakujú ("aký je recept na..."). Cache odpovede pri Tailscale gateway. TTS odpovede sa tiež cacheujú. Cache invalidácia pri model update (hash check).

Pre nás: instant odpoveď na opakované otázky. Pre iných: 10x nižšie GPU využitie pre rodinné použitie.
VISION 09
GPU Composable Fabric

Dynamic multi-GPU workload balancing. 2 GPU (RTX 5060 Ti + RTX 4060 Ti) — SGLang na GPU0 pre chat, vLLM na GPU1 pre code generation. NMR posiela GPU affinity s requestom. Docker compose s NVIDIA_VISIBLE_DEVICES sa dynamicky mení.

Pre nás: oba GPU využité efektívne. Pre iných: automatické škálovanie AI podľa load.
VISION 10
Zero-Knowledge Telemetry

Differential privacy — každá metrika má pridaný noise (Laplace mechanism). avg_latency = real_avg + noise(ε=0.1). Trend je viditeľný, konkrétne hodnoty nie. Lokálny Grafana bez privacy leaku. Optional: --telemetry=strict vypne aj ZK.

Pre nás: vieme ako systém funguje bez leaku. Pre iných: first privacy-preserving telemetry OS.
Chapter 04
ScaRgeN Visions 11-15
5 nových vízií — rozšírenie smerom k multi-modal AI, decentralizovanej autonómii, a učiacej sa infraštruktúre.
VISION 11
Autonomous Agent Orchestrator (AAO)

Meta-agent ktorý koordinuje ostatných agentov (Hermes, OpenCode, Jarvis). AAO má prístup ku všetkým systémovým metrikám a dokáže sám rozhodnúť: "GPU je voľné, spustím background fine-tuning", alebo "Ollama pomalá, prepni na BeeLlama". Agenti komunikujú cez MCP (Model Context Protocol) — štandardizovaný tool-calling. AAO učí sa z úspešných akcií a vytvára runbooky pre budúce situácie.

Pre nás: OS sa sám optimalizuje bez zásahu. Pre iných: first self-managing AI infrastructure — ako Kubernetes operator alebo pre domáci AI stack.
VISION 12
Multi-Modal Pipeline Studio

Vizuálny drag-and-drop editor pre AI pipeline (podobne ako ComfyUI ale pre celý stack). Spoj SGLang (text) + ComfyUI (image) + MusicGen (audio) + Whisper (STT) do jedného workflow. "Nahraj fotku → AI popíše → vygeneruj hudbu na základe popisu → TTS prečíta". Pipeline sa ukladá ako DAG (Directed Acyclic Graph) — možno zdieľať ako "recepty". Verzovanie pipeline ako git.

Pre nás: komplexné multi-modal workflows bez kódovania. Pre iných: first visual AI pipeline OS — creator-friendly.
VISION 13
Adaptive Resource Governor (ARG)

AI-driven resource allocation ktorý sa učí z usage patternov. ARG vie: "po večeri rodina pozerá film → CPU na Jellyfin, GPU idle na background training". "Ráno coding session → GPU na vLLM, CPU na indexovanie". Reinforcement learning model (PPO) na CPU ktorý optimalizuje QoS (Quality of Service) pre každého používateľa. Automaticky nastavuje cgroups, Docker resource limits, GPU affinity.

Pre nás: systém sa prispôsobí denným rutinám. Pre iných: first OS ktorý sám riadi zdroje podľa toho kto ho používa.
VISION 14
Decentralized Model Marketplace

P2P model sharing cez IPFS/WebTorrent — komunita SCARLIX používateľov zdieľa fine-tuned modely bez centrálneho hubu. "Natrénoval som model na slovenské recipes — zdieľam ako SCARLIX pack". Model integrity overená cez content addressing (CIDs) + podpisy. Stiahnutie modelu = automatické healthcheck + benchmark + integrácia do NMR. žiadny App Store, žiadny vendor lock-in.

Pre nás: slovenská AI komunita môže zdieľať models. Pre iných: first decentralized AI model ecosystem — ako Homebrew ale pre AI.
VISION 15
Predictive Maintenance Engine

ML model ktorý predpovedá systémové problémy skôr ako nastanú. Analyzuje: GPU teplotu trend, VRAM fragmentáciu, disk I/O latency, Docker container restart count, SGLang TTFT degradation. "GPU temp stúpa 2°C/hod + VRAM 92% → OOM za ~4 hodiny". Automaticky: zníži max_running_requests, upozorní používateľa, pripraví BeeLlama fallback. Time-series forecasting (Prophet alebo LSTM) na historických metrikách.

Pre nás: problémy riešené skôr ako nastanú. Pre iných: first predictive home server OS — ako Tesla preventative maintenance ale pre AI.
